This repository is me building core JavaScript runtime and infrastructure primitives from scratch to understand how these systems work under the hood. The focus is on correctness, edge cases, and clear behavior rather than relying on libraries or tooling.

There is no reliance on autocomplete, AI or library shortcuts. The goal is to build understanding from first principles.

The problems in this repository are designed or inspired from common JavaScript runtime and infrastructure patterns. The problem statements are generated, but the solutions are written manually.
